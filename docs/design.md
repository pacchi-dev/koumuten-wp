# 設計ドキュメント

実装前に必ずこのファイルを読むこと。決定の「理由」は `decisions.md` に分けてある。

## 1. サイト構成とテンプレート対応

WordPress の**テンプレート階層**（リクエストされた URL から使うテンプレートを
自動で決める規約。Laravel のルーティング定義に相当するが、設定ではなく
ファイル名の規約で決まる）に沿って配置する。

| ページ | URL | テンプレート | 内容 |
|---|---|---|---|
| トップ | `/` | `front-page.php` | ヒーロー / 事業内容3つ / 施工実績(新着) / お知らせ(新着) / Instagram / 採用バナー / CTA帯 / アクセス |
| 事業内容 | `/services/` | `page-services.php` | 新築・リフォーム・外構の3件。各サービスに写真 |
| 施工実績 一覧 | `/works/` | `archive-work.php` | CPT アーカイブ。写真カード + 種別 + エリア + タイトル。種別タブで絞り込み |
| 施工実績 種別 | `/work_category/{slug}/` | `taxonomy-work_category.php` | 一覧を種別で絞り込んだ状態 |
| 施工実績 詳細 | `/works/{slug}/` | `single-work.php` | メイン写真 + 間取り図(SVG) + 物件概要テーブル + 本文 |
| 会社概要 | `/company/` | `page-company.php` | 会社情報テーブル / 沿革 / Google Map |
| 採用情報 | `/recruit/` | `page-recruit.php` | 募集要項テーブル / 応募フォーム(CF7) |
| お知らせ 一覧 | `/news/` | `home.php` | 通常投稿の一覧。カテゴリ分け |
| お知らせ 詳細 | `/news/{slug}/` | `single.php` | |
| お知らせ カテゴリ | `/category/{slug}/` | `category.php` | |
| お問い合わせ | `/contact/` | `page-contact.php` | CF7 フォーム + 電話番号 + 営業時間 |
| プライバシーポリシー | `/privacy/` | `page.php` | 汎用固定ページ |
| 404 | — | `404.php` | |

お知らせは**通常投稿**を使い、「設定 > 表示設定」で投稿ページを `/news/` に割り当てる。
CPT を増やさないのは、カテゴリ・アーカイブ・RSS を標準機能のまま使えるため。

## 3. ACF フィールド設計

**ACF は無料版を使う。Repeater と Options Page は Pro 機能のため使えない。**
回避策は `decisions.md` を参照。

### `group_kc_work`（location: post_type == work）

| name | label | type | 備考 |
|---|---|---|---|
| `location` | 所在地 | text | 例: 兵庫県姫路市 |
| `completed_at` | 竣工年月 | text | 例: 2024年3月 |
| `structure` | 構造・規模 | text | 例: 木造2階建て |
| `site_area` | 敷地面積 | text | 例: 165.29㎡（50.0坪） |
| `floor_area` | 延床面積 | text | 例: 112.60㎡（34.1坪） |
| `family` | 家族構成 | text | 任意 |
| `duration` | 工期 | text | 例: 約5か月 |
| `floor_plan_label` | 間取り | text | 例: 3LDK+WIC |
| `floor_plan` | 間取り図データ | textarea | 1行1部屋 `室名,x,y,w,h`（グリッド単位） |
| `floor_plan_note` | 間取り図の注記 | text | |

物件概要テーブルの項目は、実サイト（松尾工務店 / ネイエ設計）の実測に準拠している。

### `group_kc_front_page`（location: page_type == front_page）

タブで区切る: ヒーロー / 事業内容 / 施工実績 / お知らせ / Instagram / 採用 / CTA / アクセス。
各セクションの見出し・リード文・画像・リンク文言をすべて編集可能にする。

Instagram は Repeater が使えないため `group` 型 `instagram` の中に
`image_1`〜`image_6`（image）と `profile_url`（url）を持たせる。

### `group_kc_services` / `group_kc_company` / `group_kc_recruit` / `group_kc_contact`

それぞれ location を `page_template` ではなく **ページスラッグ**で指定する
（`page` == 該当ページ）。テンプレートファイル名に依存させない。

可変長の表（会社情報テーブル・沿革・募集要項）は Repeater が無いため
**textarea に1行1レコード `項目,値` 形式**で入力し、テーマ側でパースする。

## 5. デザイン

### 配色（CSS カスタムプロパティでトークン化）

明るい配色。既存ポートフォリオのダークテーマとは対極にする。

| トークン | 値 | 用途 |
|---|---|---|
| `--c-bg` | `#ffffff` | 背景 |
| `--c-surface` | `#f6f4f0` | セクション背景（温かみのあるオフホワイト） |
| `--c-border` | `#e2ddd4` | 罫線 |
| `--c-text` | `#1f2421` | 本文（対 白 = 15.5:1） |
| `--c-muted` | `#5c625e` | 補助テキスト（対 白 = 6.6:1） |
| `--c-brand` | `#1f4c3f` | ブランド（深緑。対 白 = 9.7:1） |
| `--c-brand-dark` | `#16382e` | ホバー |
| `--c-accent` | `#b8763e` | 差し色（木のトーン） |

### タイポグラフィ

Web フォントを読み込まない。日本語 Web フォントは軽いサブセットでも数百 KB あり、
「写真が主役 = 転送量が効く」という本サイトの前提と衝突するため
（`decisions.md` 参照）。OS 標準の日本語ゴシックを使う。

スケールは 1.25 倍で `--fs-*` としてトークン化する。

### レスポンシブ

390 / 768 / 1440px で横スクロールを発生させない。
タップ領域は、ボタン・ナビ・フォーム部品などの主要な操作要素で 44×44px 以上。
パンくずや文中のリンクは行の高さに制約されるため、WCAG 2.5.8（AA）の下限 24×24px 以上とする。

代替テキストはテンプレートで固定せず、メディアライブラリの値を使う
（運営者が管理画面から編集できるようにするため）。

### ヒーローのコントラスト

**文字が乗る領域のスクリムを黒 α 0.54 以上にする。**
WCAG の相対輝度で計算すると、黒 α ≧ 0.535 なら背景が純白（相対輝度 1.0）でも
白文字とのコントラストが 4.5:1 を上回る。写真を差し替えても破綻しない。

検証は `bin/verify.mjs` が合成後のスクリーンショットから
文字のバウンディングボックス内を格子状にサンプリングし、最も明るい画素で算出する。

## 6. 画像戦略（最重要要件）

トップの `<img>` 中央値が 55 枚という業界実測がある以上、画像最適化が品質を決める。

### `add_image_size()` で定義するサイズ

| 名前 | サイズ | crop | 用途 |
|---|---|---|---|
| `sk-hero` | 1920×1080 | true | ヒーロー |
| `sk-hero-sp` | 800×1000 | true | ヒーロー(縦長・スマホ) |
| `sk-card` | 800×600 | true | 施工実績カード / 事業内容カード |
| `sk-thumb` | 400×300 | true | お知らせ / Instagram グリッド |
| `sk-detail` | 1400×933 | true | 施工実績 詳細のメイン写真 |

### 方針

- 画像はすべて**アイキャッチ（または ACF image）経由**で出力する。
  WordPress が `srcset` と `sizes` を自動付与するのは登録済みの添付ファイルだけで、
  `<img src>` を手書きすると効かない
- `loading="lazy"` は WordPress 5.5 以降が自動付与する。
  ただしヒーローだけは `fetchpriority="high"` + `loading="eager"` にする
  （LCP 要素を遅延させると逆効果）
- 実測値（リクエスト数・転送量・読み込み時間）を `bin/verify.mjs` で計測し README に記載する

## 7. 間取り図（インライン SVG）

ラスタ画像にせず SVG にする理由: リクエストを増やさない / `currentColor` でテーマに追従 /
拡大しても劣化しない。

ACF の `floor_plan` textarea に 1 行 1 部屋で入力する。

```
LDK,0,0,6,4
洋室,6,0,3,3
和室,6,3,3,3
玄関,0,4,2,2
```

`室名,x,y,幅,高さ`（グリッド単位、整数または小数）。
テーマ側の `sk_render_floor_plan()` が数値を検証し、viewBox を自動計算して描画する。
方位記号（北）を右上に固定で描く。不正な行は無視する。

## 9. 完了条件

- 全ページが表示・動作する
- 390 / 768 / 1440px で横スクロールが発生しない
- ヒーローの文字と背景写真のコントラスト比が 4.5:1 以上
  （スクリムの α 下限と、合成後スクショの最悪値サンプリングの両方で確認し、数値を README に記載）
- 施工実績が種別で絞り込める
- 間取り図がインライン SVG で表示される
- CF7 のフォーム（お問い合わせ・採用応募）を送信し、Mailpit の受信箱で受信を確認できる
- トップの Instagram セクションが ACF から編集でき、外部リンクが機能する
- 施工実績・お知らせ・採用情報を管理画面から追加編集できる
- 画像に `srcset` と `loading="lazy"` が付与されている
- 390px 幅で 24×24px 未満の操作要素が無い
- すべての `<img>` に代替テキストがある
- PHP エラー・WordPress の警告が出ていない
- エスケープ・サニタイズの漏れがない
- README に「架空であることの明示」4項目と、技術要件の記載がある
